# Upstream and provenance

The source under `research_code/src/llamafactory/` was copied from the author's local modified LLaMA-Factory research tree. Several files retain LLaMA-Factory copyright and Apache-2.0 headers. The upstream framework is [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory), licensed under Apache-2.0; the Apache license text is supplied in `research_code/LICENSE-APACHE-2.0`.

The local research tree has no usable Git history or package manifest, so its exact upstream revision and the complete original training environment cannot be authenticated. `docs/SOURCE_MAP.md` records each source file and original hash. This release contains selected original research files rather than claiming that the whole local tree is a clean upstream fork.
